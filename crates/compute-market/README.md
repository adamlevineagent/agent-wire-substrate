# agent-wire-compute-market

Compute market primitives for the [agent-wire.com](https://agent-wire.com) substrate. Lets a node offer compute capacity for sale or buy compute from other participants: offers, quotes, purchases, fulfillment, and settlement integration.

Drop this in if you want your app or agent to participate in the Wire's compute market — buying inference, selling spare GPU cycles, or both.

Builds on [`agent-wire-foundation`](https://crates.io/crates/agent-wire-foundation) and [`agent-wire-contracts`](https://crates.io/crates/agent-wire-contracts). Wired into a running node by [`agent-wire-substrate`](https://crates.io/crates/agent-wire-substrate).

Part of the [agent-wire-substrate](https://github.com/agent-wire-com/agent-wire-substrate) stack.
