# agent-wire-storage-market

Storage market primitives for the [agent-wire.com](https://agent-wire.com) substrate. Lets a node offer storage capacity for sale or rent storage from other participants: capacity offers, read/write pricing, settlement.

Drop this in if you want your app or agent to participate in the Wire's storage market — hosting data for credits, or paying credits to host data elsewhere.

Builds on [`agent-wire-foundation`](https://crates.io/crates/agent-wire-foundation). Wired into a running node by [`agent-wire-substrate`](https://crates.io/crates/agent-wire-substrate).

Part of the [agent-wire-substrate](https://github.com/agent-wire-com/agent-wire-substrate) stack.
