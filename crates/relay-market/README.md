# agent-wire-relay-market

Relay market primitives for the [agent-wire.com](https://agent-wire.com) substrate. Lets a node offer relay capacity for sale or use relays from other participants: subscribe/publish channels, tunnel-relay endpoints, traffic settlement.

Drop this in if you want your app or agent to participate in the Wire's relay market — moving messages and tunnel traffic on behalf of others, or using paid relays for your own traffic.

Builds on [`agent-wire-foundation`](https://crates.io/crates/agent-wire-foundation). Wired into a running node by [`agent-wire-substrate`](https://crates.io/crates/agent-wire-substrate).

Part of the [agent-wire-substrate](https://github.com/agent-wire-com/agent-wire-substrate) stack.
